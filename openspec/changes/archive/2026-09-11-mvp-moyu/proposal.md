# Proposal: 墨鱼 Moyu —「伪装 AI」聊天式小说阅读器

## 为什么做

用户想自建一个个人工具：把本地 TXT 小说导入一个可部署在服务器上的 Web 应用，然后在一个长得像 ChatGPT 的聊天界面里「读小说」。用户在对话框输入「下一章」，界面会模仿 AI 大模型逐字流式地"生成"出小说正文——实际上内容完全来自本地导入的原著，没有任何 AI/模型/API key 依赖。

### 核心价值
- **体验真实**：打字机光标、SSE 流式出字、伪 AI 开场与收尾，让"读本地小说"像在跟大模型对话。
- **零依赖**：不调用任何外部 AI 服务、不需要 API key、不上传任何数据，纯本地/自托管。
- **自托管**：Docker Compose 一键部署，SQLite 单文件存储，个人使用不引入多租户/用户体系复杂度。

### 非目标（Non-goals）
- 不做多用户 / 账号体系 / 权限隔离（仅一个共享访问密码，不做注册与角色）。
- 不做 AI 续写 / 内容生成——所有文本 100% 来自导入的原著。
- 不做 EPUB/PDF/Word 解析（v1 仅 TXT，Reader 接口预留扩展位）。
- 不做划词批注 / 笔记（延后至 v1.x）。
- 不做编程小说 / 语音朗读 / 多语言。

### 成功标准
1. `docker compose up` 后浏览器可访问，用访问密码登录后能导入一个 TXT 小说（含 GBK 编码文件）。
2. 输入「下一章」后，界面以视觉上类似 LLM 的流式效果展示下一章正文。
3. 支持「上一章 / 下一章 / 跳章 / 书单 / 切书 / 搜索 / 进度记忆」七类聊天指令（外加任意输入的兜底引导）。
4. 支持断句续读（重开从章节内断点继续）与阅读进度百分比。
5. 提供「快速阅读」开关（流式 vs 一次性展示正文）。
6. 全部测试通过（pytest + vitest + Playwright 冒烟），含并发/编码/回滚/SSE 报文测试。
