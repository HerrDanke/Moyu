# Proposal: 设置面板与「思考强度」

## 为什么做

现在几个开关（主题 / 阅读宽度 / 快速阅读 / 退出登录）都堆在侧栏底部，没有分组也没有标题，侧栏越长越乱。而且**最影响阅读体验的「文字生成速度」是服务端环境变量 `TYPING_SPEED`**，改一次要登服务器改配置重启——用户完全没法自己调。

顺带一个产品机会：把「生成速度」包装成 **AI 的「思考强度」**，正好贴合本项目「伪装成大模型对话」的核心卖点——越慢不是"卡"，而是"思考得更深"。

## 变更范围

- **新增「设置」入口与面板**：侧栏底部放一个设置按钮，点开为对话框
- **新增「思考强度」滑杆（4 档）**：控制正文逐字出现的节奏；档位文案走"思考深度"叙事
- **收纳既有开关**：主题切换、阅读宽度、快速阅读、退出登录全部移入设置面板
- **侧栏瘦身**：只保留 书架 + 导入 +（进度）+ 设置入口 + 用户区

## 非目标（Non-goals）

- 不做主题的跨设备同步（见下方说明）
- 不做自定义打字曲线、逐句间隔微调、跳过动画等进阶项
- 不把「用户管理」移入设置（它是管理员专属，且已有独立入口）
- 不改 SSE 协议与前端渲染方式，只改**节奏参数从哪来**

## 一个明确的技术取舍

「按用户生效」对**思考强度**成立（它是服务端行为，必须存服务端）。但**主题与阅读宽度仍保存在浏览器 localStorage**：首屏防闪烁依赖 CSS 之前的内联脚本直接读 localStorage，若改为等接口返回再应用，必然出现一次浅→深闪烁。这是有意保留的取舍，不是遗漏。

## 成功标准

1. 侧栏底部有「设置」按钮，点开出现设置面板（键盘可达：Esc 关闭、焦点回到按钮）。
2. 面板内含 4 档「思考强度」滑杆，拖动/切换后**立即影响接下来章节的出字节奏**。
3. 该设置**按用户保存**，刷新页面、换浏览器登录同一账号后仍然生效。
4. 主题 / 阅读宽度 / 快速阅读 / 退出登录 已从侧栏移入面板，功能不变。
5. 环境变量 `TYPING_SPEED` 退化为**默认值**：用户没设置过时以它为准。
6. 既有功能零回归；全量测试通过。
