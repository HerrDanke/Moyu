# Design: 阅读快捷工具条与章节目录

## 技术策略

纯前端改造，**后端零改动**。目录数据用现成的 `GET /api/books/{id}/chapters`（返回 `index_no`/`title`/`char_count`），跳转复用已有的对话指令。

## 阅读工具条

位置：输入框（composer）正上方，与阅读列同宽。

```
┌──────────────────────────────────────────┐
│ [下一章] [上一章] [目录] [跳转章节]        │  ← 工具条
│ ┌────────────────────────────────────┐   │
│ │ 说「下一章」继续阅读…          (↑) │   │  ← 输入框
│ └────────────────────────────────────┘   │
└──────────────────────────────────────────┘
```

| 按钮 | 行为 |
|---|---|
| 下一章 | 发送 `下一章` |
| 上一章 | 发送 `上一章` |
| 目录 | 打开章节抽屉（不发消息） |
| 跳转章节 | 把输入框预填为 `第 ` 并聚焦、光标置尾（不发消息） |

- 发送类按钮（下一章/上一章）在**流式生成中禁用**，与输入框的禁用状态一致
- 「目录」「跳转」不触发发送，生成中也可用（只读操作）
- 样式：小号次级按钮（`--r-pill`、1px 描边、悬停 `--bg-hover`），不喧宾夺主
- 窄屏：工具条 `overflow-x: auto`，按钮 `flex: 0 0 auto`，不换行、不破版

## 章节目录抽屉

### 数据与规模

《宠魅》有 **1807 章**。一次性渲染 1807 个 DOM 行在低端设备上会卡，因此做**轻量窗口化**：

- 容器高度固定，内部放一个高度 = `行数 × 行高` 的占位元素撑开滚动条
- 只渲染可视窗口 ± 若干行（`start..end`），用 `transform: translateY(start × rowH)` 定位
- 行高固定（32px），因此索引计算是 O(1)，无需测量

实现约 40 行，不引入 `react-window` 之类的依赖。

### 结构

```
┌── 目录 ───────────────────── ✕ ┐
│ 🔍 [搜索章节标题…]              │
├────────────────────────────────┤
│  第 1 章  魇魔岛                │
│  第 2 章  生存的本能            │  ← 当前章高亮 + 打开时自动滚到可见
│  …（只渲染可视窗口）…           │
└────────────────────────────────┘
```

- 打开时：拉取章节列表 → 按当前章号计算滚动位置 → 高亮当前章
- 搜索：**客户端过滤**已加载的列表（标题子串匹配）；过滤后索引映射回原列表以支持跳转
- 点击某章：发送 `第 N 章` 给对话引擎（走既有流程 → 进度、流式输出都自动正确），并关闭抽屉
- 关闭：Esc、点遮罩、点关闭按钮；焦点回到「目录」按钮
- 无障碍：`role="dialog"` + `aria-modal`、焦点陷阱、每行是可聚焦按钮并带 `aria-current`

### 抽屉位置

右侧滑出（宽 `min(360px, 88vw)`），移动端近似全屏。左滑出会与书架侧栏冲突，故放右侧。

## 跳转章节的预填

点「跳转章节」→ `composer` 的 textarea 值设为 `第 `，聚焦，光标移到最后。

需要给 `Composer` 加一个受控入口：把 `value` 提升为可控（或暴露一个 `setDraft(text)` 的命令式方法）。这里选择**受控 props**：`Composer` 接收 `draft` 与 `onDraftChange`，由 `App` 持有草稿状态，工具条直接写它。这样跳转与手输共用同一份状态，不会出现两份真相。

## 空状态精简

现有空状态有 4 个 chip（下一章/上一章/跳到第 12 章/书单），与新工具条重复。改为：
- 保留书名 + 进度
- 下方一句引导：「用下面的按钮开始，或直接打字告诉我」
- 去掉全部 chip

> 受影响：既有 E2E「空状态：点示例指令即开始阅读」需改为点工具条的「下一章」。

## 可测试性

新增 `data-testid`：
`reading-toolbar` · `toolbar-prev` · `toolbar-next` · `toolbar-toc` · `toolbar-jump` ·
`toc-drawer` · `toc-search` · `toc-close` · `toc-current` · `toc-item-{index}`

## 风险与缓解

| 风险 | 缓解 |
|---|---|
| 1807 章渲染卡顿 | 窗口化只渲染可视区域；行高固定便于索引 |
| 搜索后索引错乱跳到错章 | 过滤结果保留原始 `index_no`，跳转用它而不是数组下标 |
| 窄屏工具条挤压布局 | 横向滚动 + `flex: 0 0 auto` |
| 生成中点击造成并发指令 | 发送类按钮与输入框同源禁用 |
| 草稿出现两份真相 | 草稿状态提升到 `App`，受控传入 `Composer` |

## 不做的事

- 不引入虚拟列表 / 组件库
- 不做章节分组、书签、已读标记
- 不改后端与 SSE 协议
